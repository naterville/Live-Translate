Using This on Sunday Morning

1. Personal Earbud Mode (Single Phone / Laptop)

Open this page on Chrome or Safari, connect earbuds, select your language, and tap Start Live Mic. Place the device near a sanctuary speaker or plug in an audio interface from the sound board.

2. For Full Live AI Translation

Open API & Voice and add a Google Gemini or OpenAI API key so any spoken sentence is translated naturally in real time with church/scripture context.

3. Broadcasting to Multiple Attendees

To let 50+ attendees listen on their own phones from one pulpit mic, host this front end with a lightweight WebSocket relay (e.g., Deepgram or OpenAI Realtime API + a Node/Supabase channel) so the sound booth transcribes once and streams text/audio to QR-code listeners.
